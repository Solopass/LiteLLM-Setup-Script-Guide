1 Prerequisites: What You Need First

Before running the scripts, verify you have these items ready on your machine. (Your progress is saved automatically)

  • Python 3.8+

    Must be installed and added to your system PATH.

  • Docker Desktop Windows requires WSL2

    Must be installed, open, and the engine actively running (check for the whale icon in your system tray). Windows users: Ensure WSL2 integration is enabled in Settings.

  • Your API Keys

    Generate your free tier keys using the Cheat Sheet below. Save them securely.

2 Deployment & Setup

1. Launch the Python GUI

Run the Master Python script (found at the bottom of this page) to launch your control panel. This will handle everything automatically.

python ai_stack_gui.py

2. Initialize Virtual Environment

Click Button 1 in the GUI. Wait for the terminal log box to confirm that the virtual environment was created and LiteLLM was installed. This isolates the Python packages from the rest of your system.

3. Start the LiteLLM Proxy

Use the web builder below to generate your config, click Paste Config and Paste .env in the Python app, and then click Button 2. The GUI will automatically start the server on Port 4000 and print the live server logs in the black text box at the bottom of the window.

3 Open WebUI Initialization

With your routing proxy running in the Python app, click Button 3 to launch Open WebUI via Docker. Once the container is running, access it in your browser at http://localhost:3000.

  • Create Admin Account: The first screen will ask you to sign up. This account is entirely local to your machine. The first account created automatically becomes the system administrator.
  • Select a Model: At the top of the screen, click the drop-down menu. You will see all the models you configured (e.g., groq-llama, nvidia-deepseek).
  • Start Chatting: Select a model and send a message. Your prompt leaves Open WebUI, hits your local LiteLLM proxy, gets authenticated, and routes to the correct provider.

4 Maintenance & Daily Use

Shutting Down

  • Simply click the "X" to close the Python GUI window. It will cleanly terminate the background proxy for you.
  • Run docker stop open-webui or click Stop in Docker Desktop to power down the frontend.

Starting Up Tomorrow

  • You do not need to run Setup (Button 1) again.
  • Just launch the Python script.
  • Click Button 2 and then Button 3.

5 Automated Fallbacks & Cost

The magic of LiteLLM is automated error handling and fallback routing. By structuring your config.yaml with multiple free providers, you essentially create an infinite free-tier API. If Groq hits a rate limit, the request silently shifts to OpenRouter.

If Rate Limited (429)
2. NVIDIA NIM
If API Down (500)
3. OpenRouter

6 Common Troubleshooting

Port 3000 or 4000 is already in use
If you get a "Port in use" error, another app (like React) is using it, or the proxy didn't close properly last time. Change the Docker port mapping in the Python script to -p 8080:8080 to fix WebUI, or restart your computer to flush out any ghost Python processes hoarding Port 4000.
Docker "Daemon not running" error
This means Docker Desktop is closed, or WSL2 is not enabled on Windows. Open Docker Desktop, go to Settings > Resources > WSL Integration, and ensure it is turned on. Keep the app open in the background.

7 Adding True Local Models (Ollama)

If you have a powerful GPU (like an RTX 3090 or 4090), you can run models entirely offline using Ollama and route them through the exact same LiteLLM proxy.

  1. Download and install Ollama.
  2. Open your computer's terminal and run: ollama run llama3.1
  3. Use the Config Builder below and click "+ Config" on the Ollama row to add it to your config.yaml. LiteLLM will automatically communicate with Ollama on http://localhost:11434.

8 Caching & Guardrails (Optional)

LiteLLM isn't just for routing; it's a production-grade gateway. You can add global configurations to your config.yaml to supercharge your stack:

litellm_settings:
  cache: true          # Saves money if you ask the same question twice
  cache_type: "redis"  # Requires a local redis container

  # Guardrails (Requires PII masking setup)
  pii_masking: true

11 The Universal GUI Script

Want to automate everything? Save this as ai_stack_gui.py. This Python script uses tkinter to create a graphical interface that works universally on Windows, Mac, and Linux. Use the Config Builder above, click copy, and then paste directly inside this Python GUI! 

import tkinter as tk
from tkinter import scrolledtext
import subprocess, os, threading, sys

CONFIG_FILE = "config.yaml"
ENV_FILE = ".env"

class AIStackManager:
    def __init__(self, root):
        self.root = root
        self.root.title("Universal AI Stack Manager")
        self.root.geometry("600x520")

        # UI Elements
        tk.Label(root, text="Step 1: Paste configurations from the Web Builder", font=("Arial", 10, "bold")).pack(pady=(15,5))

        btn_frame = tk.Frame(root)
        btn_frame.pack(pady=5)
        tk.Button(btn_frame, text="📋 Paste config.yaml", command=self.paste_config, bg="#10b981", fg="white", width=20).pack(side=tk.LEFT, padx=5)
        tk.Button(btn_frame, text="📋 Paste .env (Keys)", command=self.paste_env, bg="#8b5cf6", fg="white", width=20).pack(side=tk.LEFT, padx=5)

        tk.Label(root, text="Step 2: Control Panel", font=("Arial", 10, "bold")).pack(pady=(15,5))

        tk.Button(root, text="1. Setup Python Venv (Runs once)", command=lambda: self.run_bg(self.setup_venv)).pack(pady=2)
        tk.Button(root, text="2. Start LiteLLM Proxy", command=lambda: self.run_bg(self.start_proxy)).pack(pady=2)
        tk.Button(root, text="3. Start Open WebUI (Docker)", command=lambda: self.run_bg(self.start_docker)).pack(pady=2)

        tk.Frame(root, height=1, bg="#475569").pack(fill="x", pady=15, padx=20)

        self.log_area = scrolledtext.ScrolledText(root, width=70, height=14, state='disabled', bg="#1e293b", fg="white")
        self.log_area.pack(pady=5)
        self.log("Ready. Awaiting commands...")

        # Graceful shutdown handler
        self.root.protocol("WM_DELETE_WINDOW", self.on_closing)
        self.proxy_process = None

    def log(self, msg):
        self.log_area.config(state='normal')
        self.log_area.insert(tk.END, msg + "\n")
        self.log_area.see(tk.END)
        self.log_area.config(state='disabled')

    def paste_config(self):
        try:
            data = self.root.clipboard_get()
            if "model_list:" in data:
                with open(CONFIG_FILE, "w") as f: f.write(data)
                self.log("Success: Saved config.yaml from clipboard!")
            else:
                self.log("Error: Clipboard doesn't look like a valid LiteLLM config.")
        except: self.log("Error: Clipboard is empty.")

    def paste_env(self):
        try:
            data = self.root.clipboard_get()
            if "=" in data or "API_KEY" in data:
                with open(ENV_FILE, "w") as f: f.write(data)
                self.log("Success: Saved .env keys from clipboard!")
            else:
                self.log("Error: Clipboard doesn't look like a valid .env file.")
        except: self.log("Error: Clipboard is empty.")

    def run_cmd(self, cmd, is_proxy=False):
        self.log(f"> {cmd}")
        try:
            # We use shell=False for the proxy to prevent Zombie processes from keeping Port 4000 open
            use_shell = not is_proxy
            args = cmd if use_shell else cmd.split(" ")

            # bufsize=1 ensures line-by-line real-time streaming in the GUI terminal
            process = subprocess.Popen(args, shell=use_shell, stdout=subprocess.PIPE, stderr=subprocess.STDOUT, text=True, bufsize=1)

            if is_proxy:
                self.proxy_process = process

            for line in process.stdout:
                self.root.after(0, self.log, line.strip())
        except Exception as e:
            self.root.after(0, self.log, f"Error: {str(e)}")

    def run_bg(self, func): threading.Thread(target=func, daemon=True).start()

    def setup_venv(self):
        python_cmd = "python" if sys.platform == "win32" else "python3"
        self.run_cmd(f"{python_cmd} -m venv venv")
        pip_cmd = "venv\\Scripts\\pip" if sys.platform == "win32" else "venv/bin/pip"
        self.run_cmd(f"{pip_cmd} install litellm[proxy]")

    def start_proxy(self):
        if not os.path.exists(CONFIG_FILE):
            self.log(f"Warning: {CONFIG_FILE} not found. Please paste it first!")
            return
        if self.proxy_process and self.proxy_process.poll() is None:
            self.log("Warning: Proxy is already running!")
            return

        # Must explicitly define .exe on Windows when shell=False to prevent FileNotFoundError
        proxy_cmd = "venv\\Scripts\\litellm.exe" if sys.platform == "win32" else "venv/bin/litellm"
        self.run_cmd(f"{proxy_cmd} --config {CONFIG_FILE}", is_proxy=True)

    def start_docker(self):
        # Using a volume (-v) ensures users do not lose their chat history when the container stops!
        # We cleanly remove yesterday's stopped container first so Day 2 boots perfectly.
        self.log("Initializing Docker environment...")
        remove_cmd = "docker rm -f open-webui"
        try: subprocess.run(remove_cmd, shell=True, stdout=subprocess.DEVNULL, stderr=subprocess.DEVNULL)
        except: pass

        # CRITICAL: Bridge Docker back to the host machine (LiteLLM) using host.docker.internal
        # so Open WebUI can successfully see your configured models on Port 4000!
        self.run_cmd("docker run -d -p 3000:8080 --add-host=host.docker.internal:host-gateway -v open-webui:/app/backend/data -e OPENAI_API_BASE_URL=http://host.docker.internal:4000/v1 -e OPENAI_API_KEY=sk-local-litellm --name open-webui ghcr.io/open-webui/open-webui:main")
        self.log("Docker starting. Access at http://localhost:3000")

    def on_closing(self):
        self.log("Shutting down... Cleaning up background processes.")
        if self.proxy_process:
            try: self.proxy_process.terminate()
            except: pass
        self.root.destroy()

if __name__ == "__main__":
    root = tk.Tk()
    app = AIStackManager(root)
    root.mainloop()
